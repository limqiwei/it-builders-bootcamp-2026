# IT Builders Bootcamp 2026

IT Builder Bootcamp is a introduction to computers and python for children aged 10 - 12 years old.
Welcome to my code repository  where I keep all the practice programs for the bootcamp.

## What's inside?
The Day 1 examples include

* **Logic Practice:** Boolean algebra and decision-making problems.
* **The Shape-Maker:** Programs that use loops to draw patterns.

## How to run my code
1. Make sure you have Python installed on your computer.
2. Download the `.py` file you want to try.
3. Open your terminal or command prompt.
4. Type `python filename.py` and hit Enter!
