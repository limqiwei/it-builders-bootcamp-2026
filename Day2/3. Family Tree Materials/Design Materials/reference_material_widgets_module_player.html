🌗 Light / Dark Mode

CSS + JS
One button that flips your whole page (and your family tree) between light mode and dark mode.

Here we only flip this little box, so the rest of the gallery stays visible. On your own page, copy the code exactly as shown — it flips document.body, so it flips your WHOLE page.

How to use: Copy the CSS into your <style> section, and the JS into your <script> section. Then add the two buttons anywhere in your <body>. The family-chart tool already reads --background-color and --text-color off the .f3 element — that's why setting them is enough to re-theme your whole tree.
Style code (copy into <style>) 
.f3.dark-mode {
  --background-color: #1e1e1e;
  --text-color: #f5f5f5;
}
Script code (copy into <script>, after your chart is created) 
const treeElement = document.getElementById('FamilyChart');

function turnOnDarkMode() {
  treeElement.classList.add('dark-mode');
  document.body.style.backgroundColor = '#1e1e1e';
  document.body.style.color = 'white';
}

function turnOnLightMode() {
  treeElement.classList.remove('dark-mode');
  document.body.style.backgroundColor = 'white';
  document.body.style.color = 'black';
}
Buttons (copy into <body>) 
<button onclick="turnOnLightMode()">☀️ Light</button>
<button onclick="turnOnDarkMode()">🌙 Dark</button>

🔍 Click a Photo to Zoom In

JS + <dialog>
Click any person's photo below — a popup box is built by JavaScript and shows the photo bigger.

Click a photo above to try it

How to use: Copy this into your <script> section, after your chart is created. Unlike Teacher Joshua's version, this one doesn't need a <dialog> already sitting in your HTML — the JavaScript builds a brand new one, shows it, then throws it away each time.
Script code (copy into <script>) 
function showImagePopup(imageUrl) {
  const dialog = document.createElement('dialog');

  const img = document.createElement('img');
  img.src = imageUrl;
  img.style.maxWidth = '100%';

  const closeBtn = document.createElement('button');
  closeBtn.textContent = 'Close';
  closeBtn.onclick = function () {
    dialog.close();
  };

  dialog.appendChild(img);
  dialog.appendChild(closeBtn);
  document.body.appendChild(dialog);

  dialog.showModal();

  dialog.addEventListener('close', function () {
    dialog.remove();
  });
}

function connectPhotosToPopup() {
  const photos = document.querySelectorAll('#FamilyChart .card img');
  photos.forEach(function (photo) {
    photo.style.cursor = 'pointer';
    photo.addEventListener('click', function (event) {
      event.stopPropagation();
      showImagePopup(photo.src);
    });
  });
}

connectPhotosToPopup();
f3Chart.setAfterUpdate(connectPhotosToPopup);

❓ Are You Sure? (Confirm Popup)

JS Basics
A yes/no popup that asks before doing something you can't easily undo — like deleting a family member.
How to use: confirm(...) is built into every browser — no library needed. It pauses your page and waits for the person to click OK or Cancel, then gives you back true or false.
Script code (copy into <script>) 
function tryDelete() {
  const isSure = confirm('Delete this person? This cannot be undone.');

  if (isSure) {
    console.log('Deleting now...');
  } else {
    console.log('Cancelled - nothing was deleted.');
  }
}
Button (copy into <body>) 
<button onclick="tryDelete()">🗑️ Delete Person</button>

⏱️ 3-2-1 Countdown

JS Basics
Counts down from 3, then shows "Let's go!". Useful before revealing something exciting.
3
How to use: setInterval(...) repeats the code inside it every 1000 milliseconds (1 second), until you tell it to stop with clearInterval(...).
Script code (copy into <script>) 
let count = 3;
const countdownText = document.getElementById('countdownText');

function startCountdown() {
  countdownText.textContent = count;

  const timer = setInterval(function () {
    count = count - 1;

    if (count > 0) {
      countdownText.textContent = count;
    } else {
      countdownText.textContent = "Let's go!";
      clearInterval(timer);
      count = 3;
    }
  }, 1000);
}
HTML (copy into <body>) 
<div id="countdownText">3</div>
<button onclick="startCountdown()">▶️ Start</button>

🎬 Reveal / Hide a Curtain

JS + Animation
Click either side of the curtain below — it slides away and disappears, revealing what's behind it.
🎉 Ta-da!
Click me
Click me
How to use: .animate(...) is built into the browser — it slides an element sideways and fades it out, then .remove() deletes it from the page.
Script code (copy into <script>) 
function slideAway(element, direction) {
  const startX = 0;
  const endX = direction === 'left' ? '-100%' : '100%';

  const animation = element.animate(
    [
      { transform: 'translateX(' + startX + 'px)', opacity: 1 },
      { transform: 'translateX(' + endX + ')', opacity: 0 }
    ],
    { duration: 700, easing: 'ease-out', fill: 'forwards' }
  );

  animation.onfinish = function () {
    element.remove();
  };
}

document.getElementById('curtainLeft').addEventListener('click', function () {
  slideAway(document.getElementById('curtainLeft'), 'left');
  slideAway(document.getElementById('curtainRight'), 'right');
});

document.getElementById('curtainRight').addEventListener('click', function () {
  slideAway(document.getElementById('curtainLeft'), 'left');
  slideAway(document.getElementById('curtainRight'), 'right');
});
Want the fancier version from Teacher Joshua's demo? That one asks "Are you sure?" first, then counts down 3-2-1, THEN reveals. That's more than 3 steps stitched together, so build it yourself out of pieces you already have:
  1. Use Example 11's confirm(...) — only continue if it returns true.
  2. If confirmed, call Example 12's startCountdown().
  3. Instead of showing "Let's go!" when the countdown finishes, call this example's slideAway(...) on both curtain pieces.

🧩 Family Tree Card Spacing

JS Fix

4-person sample tree with big cards, just for this demo — start on "Too Tight" and watch the lines reappear as you space things out

🖼️ Background Picker (File or Link)

JS Basics
Your family tree page already has a changeBackground() function with one hardcoded picture. Turn it into a dropdown so you can pick from a few — using a web link OR the name of a picture file sitting next to your page.

If a picture doesn't show up, either the link is broken or that filename isn't sitting next to the page — check the spelling! (The X-Wing option really works here, because that file is really sitting next to this gallery.)

How to use: Find function changeBackground() in your <script> and replace it with the version below, then add the dropdown to your <body>. In each <option value="...">, the value can be a web link starting with https://, OR just a plain filename like my-photo.png — that means "a picture sitting in the same folder as this page." Get the spelling and the file ending (.png, .jpg...) exactly right.
Script code (replace changeBackground() in your <script>) 
function changeBackground(source) {
  document.body.style.backgroundImage = 'url(' + source + ')';
  document.body.style.backgroundSize = 'cover';
  document.body.style.backgroundRepeat = 'no-repeat';
}
Dropdown (copy into <body>) 
<select onchange="changeBackground(this.value)">
  <option value="https://picsum.photos/seed/ocean/1200/800">Ocean</option>
  <option value="https://picsum.photos/seed/forest/1200/800">Forest</option>
  <option value="my-photo.png">My Own Photo</option>
</select>
