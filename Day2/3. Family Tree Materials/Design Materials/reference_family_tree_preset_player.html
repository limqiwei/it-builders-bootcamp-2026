🎛️ Family Tree Style Picker

Mix and match — five independent dropdowns, one live tree.

Everyone's project starts from the same base.html. This page is just for browsing ideas — the family shown is made up, and nothing here needs downloading. Each dropdown changes one thing the family-chart plugin actually supports, so you can mix any Look with any Background with any Shape. Once you find a combo you like, copy the matching CSS/JS into your own project — the same techniques are already in examples.html's "Family Tree" category.
